## 🚀 Быстрый старт

### Вариант 1: Локальный запуск

1. **Скачайте файлы проекта:**
```bash
git clone <repository-url>
cd <project-folder>
```

2. **Откройте файл в браузере:**
- Просто дважды кликните на `index.html`
- Или через терминал:
```bash
# macOS
open index.html

# Linux
xdg-open index.html

# Windows
start index.html
```

### Вариант 2: Локальный сервер (рекомендуется)

**Python 3:**
```bash
python3 -m http.server 8000
# Откройте: http://localhost:8000
```

**Node.js (npx):**
```bash
npx http-server -p 8000
# Откройте: http://localhost:8000
```

**PHP:**
```bash
php -S localhost:8000
# Откройте: http://localhost:8000
```

## 🌐 Развертывание на хостинге

### GitHub Pages (бесплатно)

1. Создайте репозиторий на GitHub
2. Загрузите все файлы
3. Перейдите в **Settings** → **Pages**
4. Выберите ветку (main/master)
5. Сохраните настройки
6. Сайт будет доступен по адресу: `https://<username>.github.io/<repo-name>/`

### Netlify (бесплатно)

1. Зарегистрируйтесь на [netlify.com](https://netlify.com)
2. Перетащите папку с файлами в Netlify Drop
3. Сайт автоматически развернётся
4. Получите бесплатный домен или подключите свой

### Vercel (бесплатно)

```bash
npm i -g vercel
cd <project-folder>
vercel
```

### Обычный хостинг (cPanel/FTP)

1. Подключитесь к хостингу по FTP (FileZilla, Cyberduck)
2. Загрузите все файлы в папку `public_html` или `www`
3. Сайт будет доступен по вашему домену

## 🔧 Настройка и кастомизация

### Изменение контактных данных

Найдите в `index.html` и замените:

```html
<!-- Email -->
<a href="mailto:globalainanutrition@gmail.com">

<!-- WhatsApp -->
<a href="https://wa.me/33667650384">

<!-- Telegram -->
<a href="https://t.me/global_aina_nutrition">
```

### Изменение цен на услуги

Найдите секцию `<!-- Services Section -->` и измените:

```html
<div class="service-price">15 €</div>
```

### Изменение цветов

В разделе `:root` в `<style>`:

```css
:root {
    --primary-bg: #FAF8F5;      /* Основной фон */
    --secondary-bg: #F5F0E8;    /* Вторичный фон */
    --accent-bg: #E8E4DE;       /* Акцентный фон */
    --text-color: #3D3D3D;      /* Цвет текста */
    --accent-color: #C9A96E;    /* Золотой акцент */
    --white: #FFFFFF;           /* Белый */
}
```

### Подключение домена

После развертывания на хостинге:

1. В `sitemap.xml` замените:
```xml
<loc>https://globalainanutrition.com/</loc>
```

2. В `robots.txt` замените:
```
Sitemap: https://globalainanutrition.com/sitemap.xml
```

## 📝 SEO и аналитика

Перед запуском: в `sitemap.xml` и `robots.txt` подставьте реальный домен. Заявки пока не сохраняются на сервере: см. `PROGRESS.md`, раздел «Открытые вопросы».

### Добавление Google Analytics

Вставьте перед закрывающим `</head>`:

```html
<!-- Google Analytics -->
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXXXXX');
</script>
```

### Регистрация в Google Search Console

1. Перейдите на [search.google.com/search-console](https://search.google.com/search-console)
2. Добавьте свой домен
3. Подтвердите владение (через HTML-файл или мета-тег)
4. Отправьте `sitemap.xml`

## 🛡️ Юридическая информация

### Дисклеймер

Сайт содержит обязательный дисклеймер в футере:

> "Все услуги предоставляются онлайн и носят консультационно-образовательный характер. Медицинская диагностика и лечение не осуществляются."

### Политики (черновики)

Страницы `privacy.html`, `terms.html` и `refund.html` созданы как **черновики**. Они закрыты от индексации (`noindex`). Перед публикацией:
- заполните поля в квадратных скобках `[...]` (адрес, срок хранения, условия возврата, применимое право);
- проверьте текст юристом (Франция, GDPR);
- уберите жёлтый баннер «Черновик» и `noindex`.
