# AINA Évidence

Коммерческий сайт и API для онлайн-консультаций по питанию, магазина цифровых гайдов и заявок. Владелец: Айна Мусхаджиева, консультант-диетолог и нутрициолог (работает онлайн из Франции).

**Статус:** разработка. Платежи выключены, публикация не выполнена. Юридические документы — черновики. Что нужно от владельца, см. `docs/ANKETA.md` и `PROGRESS.md`.

## Что внутри

- **Сайт на трёх языках:** `/ru/`, `/fr/`, `/en/`. Разделы: главная, обо мне, консультации, детское питание, питание взрослых, меню, сопровождение, магазин, гайды, отзывы, сообщество «Мамы и дети», блог, FAQ, контакты, юридические документы.
- **Заявки:** минимум данных, согласие, honeypot, подтверждение клиенту только после сохранения заявки.
- **Магазин:** карточки, предпросмотр (когда появится), корзина, оформление заказа, выдача файлов по персональной ссылке после подтверждённой оплаты.
- **Платежи:** архитектура Stripe Checkout и webhook с проверкой подписи. Выключено по умолчанию. См. `docs/PAYMENTS.md`.
- **SEO:** hreflang на всех страницах, sitemap, Open Graph, JSON-LD.
- **Без зависимостей:** Node.js 22+, встроенный SQLite. Ни один пакет из npm не нужен для работы.

## Быстрый старт

```bash
node --version              # нужен Node.js 22.13 или новее
npm test                    # тесты
npm run build               # сборка сайта в dist/
npm run check               # проверки сборки и секретов
npm run serve               # сервер на http://localhost:8080 (API + сайт)
```

Переменные окружения: `.env.example`. Файл `.env` в git не попадает.

## Публикация

```bash
npm run build:prod          # упадёт, пока не заполнены данные из docs/ANKETA.md
```

Продакшен-сборка проверяет: адрес сайта, реквизиты, сроки, цены, проверку юристом, подтверждённое содержание опубликованных товаров. Если хотя бы одно не заполнено, сборка останавливается и печатает список.

Выбор хостинга, домена и почты — решение владельца (см. `docs/ARCHITECTURE.md`, раздел 3). Ни один сервис не подключён.

## Структура

```
src/            сборщик сайта, конфиги, тексты (ru/fr/en), юридические документы
site/static/    CSS, app.js, шрифты, favicon
server/         API: заявки, заказы, webhook Stripe, загрузки, очередь писем
tests/          тесты сервера и сайта
scripts/        проверки dist/ и браузерный smoke-тест
docs/           архитектура, платежи, безопасность, бренд, анкета
private/        PDF-гайды (не в git)
data/           база и очередь (не в git)
```
