## 🚀 Запуск сайта за 3 минуты

### Вариант 1: Локальный просмотр (самый простой)

1. **Откройте файл:**
   - Дважды кликните на `index.html`
   - ИЛИ перетащите `index.html` в браузер

✅ **Готово!** Сайт откроется в браузере.

---

### Вариант 2: Локальный сервер (рекомендуется)

**Python (встроен в macOS/Linux):**
```bash
python3 -m http.server 8000
```
Откройте: **http://localhost:8000**

**Node.js:**
```bash
npx http-server -p 8000
```
Откройте: **http://localhost:8000**

---

### Вариант 3: Онлайн-хостинг (бесплатно)

#### GitHub Pages
1. Создайте репозиторий на GitHub
2. Загрузите все файлы
3. Settings → Pages → выберите ветку
4. Готово! Ваш сайт: `https://username.github.io/repo-name/`

#### Netlify
1. Зайдите на [netlify.com](https://netlify.com)
2. Перетащите папку с файлами
3. Готово! Получите бесплатный домен

#### Vercel
```bash
npm i -g vercel
vercel
```

## 🆘 Проблемы?

**Сайт не открывается:**
- Убедитесь, что файл называется `index.html`
- Проверьте, что все файлы в одной папке

**Не работают иконки:**
- Проверьте интернет-соединение (иконки Font Awesome загружаются онлайн)

**Не работают шрифты:**
- Проверьте интернет-соединение (Google Fonts загружаются онлайн)
