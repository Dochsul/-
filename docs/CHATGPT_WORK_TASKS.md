# Поручения для ChatGPT Work

Эти задачи выполняются там, где есть доступ к библиотеке ChatGPT и к Tilda. Из среды Claude эти источники недоступны. Персональные документы в чат и в GitHub не передавать.

## 1. Tilda: проект и тариф

Проект: https://tilda.cc/projects/?projectid=13114079

- Проверить, что тариф остаётся **Free**. Ничего не покупать и не менять тариф.
- Записать точный адрес сайта (вида `....tilda.ws`). Ответить им в чат Claude одним сообщением.
- Проверить, что страницы `/ru/shop/`, `/fr/shop/`, `/en/shop/` существуют и адреса совпадают с пакетом `TILDA_HANDOFF.md`.
- Создать три страницы подтверждения: `/ru/merci/`, `/fr/merci/`, `/en/merci/`. Закрыть от поисковиков. Текст подтверждения берётся из раздела «Спасибо за заказ» в `src/content/*.mjs`, **без утверждения оплаты** до ответа сервера.
- Вставить блок «Код» из `docs/TILDA_MERCI_SNIPPET.md`. Адрес API вставить только после того, как владелец его сообщит.

## 3. Регистрационные документы и юридический адрес

Источники в библиотеке: `Document_de_Synthese_J00119157360_valide(1).pdf`, `940094709.pdf`, декларация URSSAF за второй квартал 2026 года.

Задача — **не пересылать документы**, а выписать только поля, нужные для юридической страницы:
- полное юридическое название и написание имени латиницей как в документе;
- форма (entrepreneur individuel, régime micro-entreprise);
- SIREN (уже известен), код APE, дата регистрации;
- RCS / RM: применимо или нет;
- **адрес регистрации, актуальный на сегодня** (сверить с документом «Document de synthèse» и с последней декларацией URSSAF);
- режим НДС: освобождение (franchise en base de TVA) или нет (по декларации URSSAF);
- директор публикации (как записано в документе).

Куда записать: создать в Google Drive владельца текстовый файл **«AINA_registration_fields»** с этими полями (без лишнего), доступ — только владелец. Сообщить в чат Claude только название файла. Claude прочитает его через Google Drive и перенесёт в закрытый файл `private/registration.json`.
