1. Принимать заявки на онлайн-консультации и сопровождение.
2. Соответствовать требованиям платёжной системы Wise для верификации бизнеса (см. README). Требования Wise проверяйте по актуальным правилам самой Wise: в этом репозитории их нет.
3. Давать понятное, доверительное первое впечатление эксперта по питанию, без обещаний лечения и без «жёстких диет».

## 3. Аудитория (выведено из контента, **[уточнить]**)

- Взрослые, которые хотят выстроить питание без жёстких ограничений.
- Родители, которым нужна консультация по детскому питанию.
- Русскоязычная аудитория за пределами России (контент на русском).

## 4. Позиционирование и тон

- **Ключевая мысль:** «Питание, которое подходит именно вам» (H1 главной страницы).
- **Подзаголовок:** «Консультации по питанию онлайн».
- **Принципы из контента:** индивидуально, научно, бережно, конфиденциально, онлайн, системно.
- **Тон:** тёплый, спокойный, экспертный, на «вы». Без агрессивных продаж и без обещаний быстрых результатов.
- **Не использовать:** «похудеете за N дней», «вылечим», «гарантированный результат», «жёсткая диета», медицинские диагнозы и назначения.
- **Обязательная оговорка:** услуги не являются медицинской диагностикой или лечением (дисклеймер в футере). Её нельзя убирать.

## 5. Цвета (CSS-токены в `:root` `index.html`)

| Токен | HEX | Роль |
|---|---|---|
| `--primary-bg` | `#FAF8F5` | Основной фон (молочный) |
| `--secondary-bg` | `#F5F0E8` | Вторичный фон (бежевый) |
| `--accent-bg` | `#E8E4DE` | Акцентный фон, границы полей |
| `--text-color` | `#3D3D3D` | Основной текст |
| `--accent-color` | `#C9A96E` | Акцент: золото, кнопки, логотип |
| `--white` | `#FFFFFF` | Белый: шапка, карточки |

Дополнительно: `#B3261E` — цвет ошибки в форме. Для предупреждений в юридических черновиках используется `#FFF4D6`/`#5A4300`.

**Контраст (WCAG 2.x, посчитано):**

| Пара | Коэффициент | AA |
|---|---|---|
| `#3D3D3D` на `#FFFFFF` | 10.86:1 | да |
| `#3D3D3D` на `#C9A96E` | около 4.85:1 | да |
| `#C9A96E` на `#FFFFFF` | 2.24:1 | **нет** (для любого текста) |
| `#FFFFFF` на `#C9A96E` | 2.24:1 | **нет** (исправлено: текст на золоте теперь `--text-color`) |

Поэтому золото допустимо только для декора, фона и элементов без текста. Текст на золоте — тёмный (`--text-color`). Золото как цвет текста (логотип, подзаголовок `.hero-subtitle`, ссылки) **пока не проходит AA**. Замена оттенка (например, более тёмный золотой для текста) — решение владельца бренда.
