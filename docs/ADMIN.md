# Административная панель (iPhone и компьютер)

Панель открывается в браузере по адресу `https://<адрес API>/admin` и удобна с телефона: «Добавить на экран «Домой»» в Safari даёт значок приложения. Это **только чтение**: возвраты и импорт комиссий остаются в проверяемых скриптах (`scripts/record-refund.mjs`, `scripts/import-revolut-fees.mjs`).

## Что показывает

| Раздел | Что видно |
|---|---|
| Сводка | число оплаченных заказов, заказов на проверке, новых заявок, заявок за 7 дней; деньги по валютам: оплачено, возвраты, комиссии, чистыми, сколько комиссий ждут сверки |
| Заказы | 50 последних: дата, сумма, статус, страна, способ оплаты, товары, e-mail покупателя |
| Заявки | 50 последних: имя, тема, сообщение, контакты, статус |
| Учёт | CSV за период для бухгалтера (без e-mail покупателей), файл скачивается на телефон |

Токены скачиваний, хеши, идентификаторы сессий и ключи провайдеров панель **не показывает**.

## Как устроен вход

- Пароль хранится на сервере только как хеш scrypt (`ADMIN_PASSWORD_HASH`). Сам пароль нигде не записан.
- Сессия живёт 8 часов, cookie `HttpOnly`, `SameSite=Strict`, с `Secure` на https. В базе хранится только SHA-256 от токена.
- После 5 неверных попыток за 15 минут вход блокируется на это время.
- Панель закрыта от поисковиков (`noindex`), CSP запрещает сторонние скрипты и встроенный JavaScript.
- Без `ADMIN_PASSWORD_HASH` панель отключена: `/admin` и `/api/admin/*` отвечают 404.

## Шаги (один раз)

1. **Придумайте пароль** из 12 и более символов, лучше в менеджере паролей (например, в iCloud Keychain). Не отправляйте его в чат.
2. **Получите хеш на своём компьютере** из папки проекта:
   ```bash
   read -rs ADMIN_PW && printf '%s' "$ADMIN_PW" | node scripts/admin-password.mjs; unset ADMIN_PW
   ```
   Скрипт выведет строку `ADMIN_PASSWORD_HASH=scrypt:…`. Её можно передать в `.env` на сервере. Это не секрет в полном смысле, но и не для чата.
3. **Добавьте в `.env` на сервере** (файл вне git):
   ```
   ADMIN_PASSWORD_HASH=scrypt:16384:8:1:…
   ```
   Перезапустите API. Если значение похоже на обычный пароль, сервер откажется запускаться в production (проверка в `server/config.mjs`).
4. Откройте `https://<адрес API>/admin` на iPhone, войдите, при желании добавьте на экран «Домой».

## Чего панель не умеет (сознательно)

- Нет записи в базу: отмены, возвраты и комиссии меняются только скриптами, которые пишут в журнал.
- Нет двухфакторной защиты. Для владельца достаточно длинного пароля и лимита попыток; если понадобится 2FA, это отдельное решение с новым сервисом.
- Нет доступа к файлам PDF: они выдаются только по персональным ссылкам.

## Проверка

- `npm test`: `tests/admin.test.mjs` (15 проверок): вход, неверный пароль, cookie, сессия и срок, лимит попыток, выгрузка без e-mail, CSP и отсутствие встроенных обработчиков, данные без токенов.
- Браузер: вход и вид на ширине 390 px проверены на локальном сервере (Playwright, Chromium): вход, сообщение о неверном пароле, сводка, учёт, горизонтальной прокрутки нет.
- **Не проверено:** работа за Caddy на реальном домене (`Secure`-cookie, `TRUST_PROXY`) и Safari на iPhone. Это нужно повторить после развёртывания.
