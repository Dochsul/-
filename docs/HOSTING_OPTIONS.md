# Размещение API: бесплатные и платные варианты (ноябрь 2026)

Требования существующей архитектуры: Docker-контейнер, постоянная база SQLite (файл на диске), HTTPS по своему домену (для webhook Revolut), хранение PDF на диске, ежедневные зашифрованные копии.

Статусы: **проверено** — подтверждено в этой среде или в CI проекта; **по источникам** — из поисковых сводок, сверьте на официальной странице; **не проверено** — не открывалось.

## Вывод

1. **Полностью бесплатный запуск API в публичном интернете без карты не найден.** Облачные варианты с бесплатным постоянным диском требуют карту (Oracle) или не сохраняют данные (Render Free).
2. **Минимальные расходы:** один маленький сервер Hetzner (около 4–8 € в месяц по сводкам) плюс домен, если его нет. Это самый дешёвый надёжный путь с постоянным диском и HTTPS.
3. **Бесплатное тестирование без сервера** возможно на вашем компьютере: `npm test`, `npm run e2e:tilda` и `npm run e2e:tilda:stripe` работают без интернета и без карты. Настоящий webhook Revolut требует публичного адреса, поэтому боевой сквозной тест на компьютере не даёт полной картины.
4. **Docker на компьютере** (Docker Desktop) — для личного использования бесплатен по условиям Docker; проверьте условия на сайте Docker перед установкой.
