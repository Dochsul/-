# Пакет для ChatGPT Work: Tilda, проект №13114079

Доступа к редактору Tilda у меня нет. Этот документ — точная инструкция для ChatGPT Work. Работать только с существующим проектом №13114079. Новый сайт не создавать.

## 1. Что передаётся

| Что | Где в репозитории |
|---|---|
| Тексты 16 страниц × 3 языка (ru, fr, en) | `tilda/pages/NN-*.md` |
| SEO: title, description, robots, hreflang | `tilda/seo.csv` (48 строк) |
| T123-блоки (шапка, формы, блоки магазина) | `tilda/components/*.html` |
| Юридические тексты с реквизитами (только в приватной копии) | `private/tilda-filled/pages/` (не в git) |

Публичная копия содержит маркеры `[из личного реестра: legal.*]` вместо реквизитов. Заполненные тексты для вставки — в приватной копии.

## 2. Структура 48 страниц (лимит Tilda Free — 50)

Страницы на каждый язык (`/ru/…`, `/fr/…`, `/en/…`):

1. Главная (home)
2. О проекте (about)
3. Консультации (consultations) — черновик, не публиковать
4. Детское питание (child-nutrition) — черновик
5. Питание взрослых (adult-nutrition) — черновик
6. Меню (menus) — черновик
7. Поддержка (support) — черновик
8. Магазин (shop)
9. Гайды (guides)
10. Отзывы (reviews)
11. Сообщество (community)
12. Блог (blog)
13. FAQ (faq)
14. Контакты (contact)
15. Юридические сведения и конфиденциальность: `legal/privacy` — блоки с якорями `privacy`, `cookies`, `mentions`
16. Условия продажи: `legal/terms-of-sale` — блоки с якорями `terms`, `refunds`, `digital`

Ссылки из формы заказа ведут на `legal/terms-of-sale/#refunds` и `legal/terms-of-sale/#digital`. Якорь задаётся в настройках блока Tilda («Якорь»).

## 3. Что публиковать сейчас

Публикуются только страницы со статусом `publish` в `seo.csv`. Страницы со статусом `draft` и `legal-draft` остаются скрытыми (`noindex`) до решений владельца и проверки юристом.

Продажи не включать: кнопки покупки в магазине без подключённого платежа показывают «Оплата пока не подключена». Публичный доступ и реальные платежи не активировать.

## 4. Правила, которые нельзя нарушать

- Цены не менять: 9,90 € / 1 000 ₽ (АБКМ), 9,90 € / 1 000 ₽ (сон), 7,90 € / 800 ₽ (прикорм), 19,90 € / 2 000 ₽ (комплект). Рубли выключены (`ENABLED_CURRENCIES=EUR`).
- Палитра и шрифты проекта сохранить. CSS блоков только под классом `.ae`.
- Инлайн-скрипты и атрибуты `style=` в блоках не добавлять (правило CSP сайта).
- Платные PDF в Tilda не загружать: выдача только через API после оплаты.
- Три языка: ru, fr, en. Французский текст юридически обязателен; русский и английский — неофициальные переводы.

## 5. Реквизиты в юридических текстах

Заполнены из выписки RNE (приватная копия): наименование, форма, SIREN, адрес. Остальные поля не заполнены (нет подтверждённых данных), список в `docs/ANKETA.md`.

## 6. Проверка после вставки

- Адреса страниц совпадают с `seo.csv`.
- Ссылки формы заказа открывают якоря.
- Для каждой страницы заданы title и description по `seo.csv`.
- Страницы со статусом `draft` и `legal-draft` имеют `noindex`.
