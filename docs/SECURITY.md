# Безопасность

Этот документ описывает, что защищено, как проверяется и что остаётся за владельцем.

## Угрозы и меры

| Угроза | Мера | Где проверяется |
|---|---|---|
| Подделка цены на клиенте | Цены считаются на сервере по каталогу | `tests/server.test.mjs`: «price comes from the server catalog» |
| Поддельный webhook оплаты | HMAC-SHA256 по `Stripe-Signature`, допуск 5 минут | тесты подписи, старого timestamp |
| Повторная обработка события | Таблица `processed_events` | тест «duplicate» |
| Выдача файла без оплаты | Файлы выдаются только для заказа в статусе `paid` | тест «unpaid orders get 404» |
| Перебор токенов | Токен 256 бит, в БД только SHA-256, rate limit | тест «malformed token» |
| Повторное скачивание сверх лимита | Атомарный `UPDATE ... WHERE download_count < max` | тест «download limit» |
| Утечка ссылки навсегда | Срок 7 дней (предложение, подтвердить), отзыв через `revoked` | тест «expired, revoked» |
| Прямой доступ к PDF | Файлы вне `dist/`, в `private/`, доступны только через API | структура каталогов, `.gitignore` |
| Path traversal | Нормализация путей, проверка префикса | тест «static: path traversal» |
| Спам и боты в формах | Honeypot, rate limit по IP, лимит размера тела | тесты «honeypot», «rate limited» |
| Сбор чувствительных данных | Форма не принимает анализы и диагнозы, такие заявки отклоняются | тест «health data» |
| XSS | Экранирование всего вывода, CSP без inline-скриптов и обработчиков | `tests/site.test.mjs`: CSP compatibility |
| Clickjacking | `X-Frame-Options: DENY`, `frame-ancestors 'none'` | тест заголовков |
| Утечка секретов в репозиторий | `.env` в `.gitignore`, `.env.example` без значений, CI-проверка | `.github/workflows/ci.yml` |
| Перехват трафика | HTTPS (на хостинге), HSTS в `_headers` | `dist/_headers` |
| Персональные данные в логах | Логируется только тип ошибки, без тела запроса | `server/app.mjs` |

## Что проверено автоматически
- Все тесты: `npm test` (46 проверок: 31 серверная и 15 сайтовых).
- Статический анализ CI: сборка, тесты, проверка ссылок.

## Что не проверено и требует внимания владельца
- **Аудит внешней безопасности** (penetration test) не проводился. Рекомендуется перед запуском платежей.
- **Зависимости:** проект не имеет runtime-зависимостей. Если появятся, подключить `npm audit` и Dependabot (бесплатно в GitHub).
- **Хостинг:** заголовки сервера и HTTPS зависят от выбранного хостинга (см. `docs/ARCHITECTURE.md`).
- **Резервные копии** базы `data/app.db`: настроить на сервере (cron + шифрование). Не реализовано.
- **Хранение IP:** в базе только соленый хеш. Соль задаётся `IP_SALT` и должна быть секретной.
