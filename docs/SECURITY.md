# Безопасность

Что защищено, чем это подтверждено и что остаётся не проверенным. Дата: 26 ноября 2026. Тесты: `npm test` (**125 проверок**), `npm run e2e:tilda` (**40 проверок в браузере**).

Уровни подтверждения: **Т** — автотест, проверяющий именно это поведение; **М** — тест доказал, что проверка работает: я намеренно ломал код (мутация), и нужный тест падал; **К** — проверено чтением конфигурации и разбором парсером, но не запуском.

## Что не проверено

- **Аудит внешней безопасности (пентест)** не проводился и рекомендуется перед боевыми платежами.
- **Запуск в Docker и работа Caddy** не проверены: в среде разработки нет демона Docker.
- **Реальные Stripe, Backblaze B2, Cloudflare R2, SMTP-сервисы**: проверены только заглушками с настоящими протоколами и схемами подписи.
- **Права доступа на сервере и обновления ОС** зависят от провайдера и вашей эксплуатации.
- **Нагрузочное тестирование** не проводилось.
- **Зависимости:** у проекта нет runtime-зависимостей; для тестов браузера используется Playwright (в CI закреплена версия 1.49.1). Dependabot и `npm audit` подключите, если появятся пакеты.
- Блок T123 в самой **Tilda**: CSP страницы Tilda мне недоступен, поэтому поведение блока на реальном сайте не проверено.
