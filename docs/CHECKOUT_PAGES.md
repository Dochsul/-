# Адреса страниц после оплаты и отмены (для Tilda и ChatGPT Work)

Сайт в Tilda публикуется на адресе, который у вас уже есть: поддомен `*.tilda.ws` или ваш собственный домен, если он подключён. Новый домен для этого не нужен.

API сам подставляет язык в адрес. Шаблоны, которые записываются в `.env` (через `deploy/setup-server.sh`):

- Страница после оплаты: `https://<адрес-сайта>/{locale}/merci/`
- Страница отмены: `https://<адрес-сайта>/{locale}/shop/`

Где `{locale}` — `ru`, `fr` или `en`. Итоговые адреса:

| Язык | Успешная оплата | Отмена оплаты |
|---|---|---|
| Русский | `https://<адрес-сайта>/ru/merci/` | `https://<адрес-сайта>/ru/shop/` |
| Французский | `https://<адрес-сайта>/fr/merci/` | `https://<адрес-сайта>/fr/shop/` |
| Английский | `https://<адрес-сайта>/en/merci/` | `https://<адрес-сайта>/en/shop/` |

## Что должно существовать в Tilda

- Три страницы «merci» (спасибо за заказ) — по одной на язык, с текстом «Оплата получена. Ссылки на файлы придут на вашу почту» (тексты подготовит ChatGPT Work из `TILDA_HANDOFF.md`; слово «merci» в адресе — техническое). Страницы не индексируются поисковиками.
- Страница магазина `/ru/shop/`, `/fr/shop/`, `/en/shop/` уже входит в пакет (страница 8).

## Что отправить ChatGPT Work (текст для копирования)

> Пожалуйста, создайте три страницы подтверждения оплаты в Tilda с адресами /ru/merci/, /fr/merci/ и /en/merci/ (русский, французский, английский). Текст: «Оплата получена. Ссылки на файлы придут на вашу электронную почту». Страницы закрыть от поисковиков. Адрес страницы отмены — существующая страница магазина /ru/shop/, /fr/shop/, /en/shop/. Ответьте, какой точный адрес сайта Tilda получился (адрес поддомена или домена).

Ассистент не может отправить это сообщение ChatGPT Work сам: у него нет доступа к вашему чату с ChatGPT Work. Вставьте текст вручную и пришлите ответ с точным адресом сайта.

## Что нужно проверить после создания страниц

1. Открыть `https://<адрес-сайта>/ru/merci/` — страница открывается без ошибки.
2. Адрес сайта совпадает с тем, что записано в `ALLOWED_ORIGINS` (тот же адрес, без `/` в конце).
