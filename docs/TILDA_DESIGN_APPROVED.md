# Утверждённый дизайн AINA ÉVIDENCE: применение в Tilda (проект 13114079)

Эталон: `AINA_Tilda_approved_design.png` (Google Drive, владелец). Дизайн утверждён окончательно. Не предлагать другие стили и не переделывать его. Эта страница описывает, как перенести утверждённый дизайн на существующий сайт Tilda. Новый сайт не создаётся.

## 1. Палитра (утверждённая, без изменений)

| Цвет | HEX | Где использовать |
|---|---|---|
| Слоновая кость | `#FFF4E9` | основной фон страниц |
| Пудрово-розовый | `#F3D6CF` | фоновые блоки, карточки |
| Нежная лаванда | `#E4D3E4` | вторичные блоки |
| Благородное золото | `#B4883E` | рамки, линии, акценты, кнопки |
| Бордовый | `#74283F` | заголовки |
| Изумрудный | `#174532` | акцентные кнопки, изумрудные элементы |

Правила, которые нельзя нарушать:
- Фон светлый, кремово-пудровый. Сплошного тёмно-зелёного фона не использовать.
- Текст на золоте — только тёмный (`#2E2427`). Золото не используется как цвет текста на светлом фоне: контраст 2,97:1 недостаточен.

## 2. Типографика

- Заголовки: с засечками, элегантные (в статическом сайте — `Cormorant`, self-hosted; в Tilda — аналог из библиотеки шрифтов Tilda, подтвердить с владельцем).
- Основной текст: гротеск без засечек (в статическом сайте — `Montserrat`).
- Логотип «AINA ÉVIDENCE» — оригинальный файл владельца, не перерисовывать.

## 3. Структура главной (по эталону, сверху вниз)

1. Шапка: логотип, навигация (Консультации, Меню, Сопровождение, Гайды, Сообщество, Обо мне, Контакты), переключатель языка RU / FR / EN.
2. Герой: «AINA ÉVIDENCE», «Питание · Дети · Здоровье семьи», «Консультации и поддержка для всей семьи», короткое описание, кнопка «Записаться на консультацию» (см. раздел 6).
3. Полоса тем: «Нутрициология», «Питание и здоровье», «Разбор анализов», «Детское питание».
4. Блоки направлений: Консультации · Индивидуальное меню · Сопровождение клиентов.
5. Гайды для родителей: «АБКМ», «Сон ребёнка 0–18 лет», «Прикорм: каши и пюре» — карточки с ценами (см. раздел 5).
6. Сообщество «Мамы и дети» — две кнопки (WhatsApp, Telegram), бесплатно.
7. Обо мне: портрет специалиста (утверждённый образ), текст о квалификации (см. раздел 6), работа онлайн с клиентами из разных стран.
8. Подвал: соцсети (@aina_evidence в Instagram; TikTok — AinaEvidence), контакты, юридические ссылки.

Остальные страницы (Консультации, Меню, Сопровождение, Детское питание, Питание взрослых, Питание женщин, Магазин, Блог, Отзывы, Контакты, юридические страницы) — тот же визуальный стиль: шапка, футер, золотые рамки, те же шрифты.

## 4. Изображения

- Портрет специалиста — **только утверждённый файл владельца** из эталона. Его не генерировать, не менять, не заменять другим образом.
- Требование владельца: хиджаб полностью закрывает волосы, уши и шею. Из среды Claude изображение не проверено визуально, эту проверку делает владелец на утверждении.
- Фото владельца (лицо) на сайте не использовать отдельно от утверждённого образа.
- Остальные изображения (мамы, дети, продукты, книги, рабочее пространство) — только реалистичные, собственные или лицензированные, с подтверждённым правом использования.

## 6. Что требует решения владельца (публиковать нельзя без него)

1. **Квалификация «Консультант-диетолог и нутрициолог»** стоит в эталоне. Ваше правило: профессиональные наименования публикуются только после юридической проверки. Слово «диетолог» во Франции защищено законом. Пока решения нет, в тексте используется «Консультант по питанию и нутрициологии» (ваша формулировка). Дизайн не меняется — меняется только текст.
2. **Кнопка «Записаться на консультацию».** Консультации — регулируемая услуга, пока в черновиках. Кнопку показать после юридического подтверждения либо вести в форму «Записаться» без обещаний.
3. **Контраст текста на золоте** — проверить при вставке в Tilda; текст на золоте только тёмный.

## 7. Что сделано и что нет

- Палитра статического сайта проверена: все шесть цветов присутствуют в `site/static/styles.css`. Дополнительные оттенки — служебные (предупреждения о черновиках).
- Адаптация под телефоны, планшеты и компьютеры: в статическом сайте есть брейкпоинты 960 px и 600 px. В Tilda адаптацию делает ChatGPT Work по этому документу.
- **Не сделано:** применение дизайна в самом проекте Tilda (доступа к tilda.cc нет). Передано ChatGPT Work. Проверка страниц на реальных устройствах — после применения.
