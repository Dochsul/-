# Бесплатная или доступная юридическая помощь для предпринимателя во Франции

Источники: поиск и сводки (проверено: номер 3039 и «point-justice» по сводкам; justice.fr — по поиску). Перед обращением сверьте адрес и условия на сайте ведомства.

## Бесплатно

| Что | Куда | Для чего |
|---|---|---|
| **Номер 3039** — национальный номер доступа к праву | по телефону 3039 | найти ближайший пункт бесплатной правовой информации, записаться на приём |
| **Points d’accès au droit (PAD)** / point-justice | по адресу из 3039 | бесплатная первичная информация: юристы, ассоциации, конциликаторы |
| **Maisons de justice et du droit** | местные отделения Министерства юстиции | бесплатная помощь и информация |
| **Conseils départementaux d’accès au droit (CDAD)** | в каждом департаменте | список бесплатных услуг в вашем районе |
| **Бесплатная первая консультация адвоката** | через barreau (коллегию адвокатов) вашего города | по сводкам, первая консультация бесплатна; дальнейшее сопровождение — платное (кроме aide juridictionnelle) |
| **Мэрия** | приёмные часы | иногда бесплатная юридическая приёмная (по совету Adie) |
| **Adie** (ассоциация микропредпринимателей) | https://www.adie.org | поддержка микропредпринимателей, справочные материалы |

## Доступно по сопровождению

- **Адвокат с фиксированными часами или договором на пакет** — договоритесь о смете до начала работы.
- **Expert-comptable (бухгалтер)** — налоги, НДС, декларации; по вопросам URSSAF и TVA.
- **Чамбры (CCI, CMA)** — информационные консультации по регистрации и статусу; уточните, есть ли бесплатные.

## Что уточнить у юриста в первую очередь

Тот же список, что в `docs/LEGAL_PLAN.md`, раздел 6. Обязательно в письменной форме:
1. Можно ли консультировать о питании без диплома и регистрации; какие формулировки допустимы.
2. Регулируемость «обзора анализов» и меню для беременных и детей.
3. Продажа цифровых PDF покупателям в ЕС и вне ЕС.
4. Тексты CGV, политики конфиденциальности, возвратов и «Mentions légales».
